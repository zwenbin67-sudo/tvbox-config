# TVBox 配置 · 国内家宽实测清单

26 个影视接口，2026-10-18 实测可用。

## 配置地址

```
https://zwenbin67-sudo.github.io/tvbox-config/index.json
```

> 首次使用前需在仓库 Settings → Pages → Source 选择 `main` 分支并保存，等 1 分钟生效。

## 分级

| 组 | 数量 | 说明 |
|---|---|---|
| A 级 | 14 | JSON、播放地址、ts 分片三层验证全通过 |
| B 级 | 9 | 可用但响应偏慢或仅 720P |
| C 级 | 3 | 部分播放地址 404，仅作补充 |

## 验证方式

1. 调用 `?ac=list` 确认返回合法 JSON
2. 调用 `?ac=detail&pg=1`，按 `vod_play_from` / `vod_play_url` 的 `$$$` 索引配对，取出真实播放地址
3. 请求 m3u8 并实际拉取首个 `.ts` / `.m4s` 分片

只通过第 1 步的接口不计入清单——"列表能下、播放 403"的假活源全部剔除。

## 更新

资源站换域名频繁，建议每两周复测。挂掉的从 `index.json` 的 `groups` 里删除对应站点即可。
